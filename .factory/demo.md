# Demo sandbox

- Entry point: <https://future-skills-portfolio.sociobot.in/?demo=1> (the `/demo` route is an equivalent direct link).
- Sample: four completed work records across six skill modes, plus four selected print challenges.
- Storage: `demo:future-skills-portfolio:v1`. Demo mode never reads or writes `future-skills-portfolio:v1`.
- Reset: **Reset demo** replaces only the demo namespace with the original sample.
- Exit: **Start for real** deletes the demo namespace and opens the real empty or saved workspace.
- Portfolio transfer: **Export portfolio JSON** includes work records, family challenges, and print-deck choices. **Import portfolio JSON** previews a file before an explicit merge or replace choice. In demo mode, either choice changes only `demo:future-skills-portfolio:v1`.

Every claim test starts from this entry point in a fresh browser context.
